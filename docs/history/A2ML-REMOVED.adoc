= The A2ML files removed from hypatia on 2026-11-14

The owner ruled on 2026-11-14, "Full migration now": every `.a2ml` file in
hypatia is translated into deed form where a mapping spec says it
translates, every reader is moved off it, and the file is deleted. The
mapping specs are in standards `1-formats/deed/mappings/`; a field a spec
does not list does not translate and was dropped, not re-homed. Files with
no mapping spec were deleted (A7 section 11, ruling Q7).

This record lists each removed file, what it was, and where its content
went. The contents are not copied here. Git history keeps them. To read one,
use its blob id, or read its path at the last commit that held it:

[source,bash]
----
git cat-file -p <blob id>
git show b660d08833729f129b0de9445b0e5ebadcddef77:<path>
----

Size is in bytes. The sha256 is of the file as it was tracked.

== Retained, with the reason

Two `.a2ml` files stay, each because a live reader outside this repository's
control still needs exactly that input. Neither has a deed form to move to.

[cols="3,5",options="header"]
|===
| Path | Why it stays

| `audits/assail-classifications.a2ml`
| panic-attack (>= 2.5.5, `load_user_classifications` in its assail module,
in the panic-attack repository) reads only `audits/assail-classifications.a2ml` or
`.panic-attack-classifications.a2ml`. No mapping spec covers it and
panic-attack has no deed reader, so deleting it would unsuppress the audited
findings it records. It goes when panic-attack reads a deed form first.

| `test/fixtures/a2ml/rsr-criteria-v2.a2ml`
| A dogfood copy of the RSR v2.0 criteria, whose canon
(`0-canon/rsr/rsr-criteria-v2.a2ml` in standards) is still A2ML: A7 section
10 gives it a criteria praxis deed written by kyX's front end (D313), not a
hand conversion. `Hypatia.Rules.RsrCriteria` must read the canon's form, and
the oracle's tests, the CI smoke run and the `rsr_score` default read this
copy. It goes when the canon has a deed form.
|===
