== HANDOVER — neural-convergence theorems (Agda, rechecked in Rocq and Lean)

=== What changed, and why

Until 2026-11-09 this handover planned the PageRank and ESN convergence
proofs in Lean 4 *with Mathlib*, in a separate `+lean4-mathlib/+` project.
That plan is withdrawn. The estate
https://github.com/metadatastician/standards/blob/9bdf864cc7f2c8e24b4df84bf00d04158eee3ad5/3-practice/PROOF-POLICY.adoc[PROOF-POLICY]
(owner rulings of 2026-10-26 and 2026-11-04, pinned here at
`+9bdf864cc7f2c8e24b4df84bf00d04158eee3ad5+`) says:

* *§1:* a statement that would be true of any implementation is *theory*.
  Convergence is the policy's own example. Theory lives in *Agda*, under
  `+agda --safe --without-K --cubical-compatible+` (§2.1).
* *§2:* every Agda theory proof is rechecked in *Rocq* and in *Lean*,
  transported through Dedukti where that works and re-proved by hand
  where it does not. *No Mathlib*: a missing lemma is re-proved in the
  core library.
* *§8:* the result is graded `+PWG-3+` (Agda checked), `+PWG-2i+` (one leg
  counted), `+PWG-2ii+` (both legs) or `+PWG-1+` (current receipts for
  every witness). A leg counts only when its kernel accepted it *and* its
  statement is `+RECONCILED+` with the Agda statement.

The inventory, with each artefact's current status, is the
`+neural-convergence+` section of `+verification/PROOF-STATUS.adoc+`.

=== The two theorems

Both are stated over an *abstract ordered commutative ring*: a record of
carrier, operations and the order and absolute-value laws the proof uses,
taken as a module parameter. That is not a postulate, so `+--safe+`
accepts it. Agda, Rocq and Lean all have no real numbers without a large
library, and real analysis is not needed: the activation and the matrix
enter only through hypotheses. Use the *bound* form of the sup norm
(`+∀ j, |x_j − y_j| ≤ δ+`) rather than defining a maximum.

==== T-RC — reservoir contraction (ESN and LSM)

Setting: `+0 ≤ a ≤ 1+`; `+ρ ≥ 0+`; an `+n × n+` matrix `+W+` with
`+Σ_j |W_ij| ≤ ρ+` for every row `+i+`; any `+σ+` with
`+|σ s − σ t| ≤ |s − t|+`; input weights `+b+`. The update is

  F_u(x)_i = (1 − a)·x_i + a·σ(Σ_j W_ij·x_j + b_i·u)

*Statement:* if `+|x_j − y_j| ≤ δ+` for every `+j+`, then
`+|F_u(x)_i − F_u(y)_i| ≤ ((1 − a) + a·ρ)·δ+` for every `+i+` and every
input `+u+`.

*Corollary (forgetting):* for an input sequence of length `+k+`, the two
trajectories from `+x+` and `+y+` stay within `+q^k·δ+`, where
`+q = (1 − a) + a·ρ+`. Prove it by induction on the sequence. This is
forgetting only when `+q < 1+`, that is when `+0 < a+` and `+ρ < 1+`; with
`+a = 0+` or `+ρ ≥ 1+` the bound is non-expansive at best. State the
contraction claim with those strict premises. Hypatia's values give
`+q+` = 0.99 for the ESN (`+a+` 0.2, `+ρ+` 0.95) and 0.97 for the LSM
(`+a+` 0.3, `+ρ+` 0.9).

*Proof outline:* the input term cancels. The recurrent difference is
`+Σ_j W_ij·(x_j − y_j)+` (distributivity), bounded by
`+Σ_j |W_ij|·δ ≤ ρ·δ+` (triangle inequality over a finite sum, `+|xy| = |x||y|+`,
monotonicity of multiplication by a non-negative). Then
`+|(1 − a)·d + a·e| ≤ (1 − a)·|d| + a·|e|+` for `+0 ≤ a ≤ 1+`.

==== T-PR — damped PageRank contraction (Graph of Trust)

Setting: `+0 ≤ d ≤ 1+`; an `+n × n+` matrix `+P+` with `+P_ij ≥ 0+` and
`+Σ_i P_ij ≤ 1+` for every column `+j+`; any constant vector `+c+`. The
map is `+G(x) = c + d·P·x+`.

*Statement:* `+Σ_i |G(x)_i − G(y)_i| ≤ d·Σ_j |x_j − y_j|+`.

*Corollary:* iterates from any two starts approach each other by `+d+` per
step in ℓ¹. That is a contraction only when `+d < 1+`; with `+d = 1+` the
statement is non-expansiveness (`+P+` the identity keeps the distance
fixed). State the contraction claim with `+0 ≤ d < 1+`. Hypatia uses
`+d+` = 0.85.

The premise is column-*sub*stochastic, `+≤ 1+`, not `+= 1+`. The earlier
handover assumed a column-stochastic `+P+`, which hypatia's code does not
produce: a node with no positive out-edges contributes a zero column.
Existence and uniqueness of the fixed point need completeness, which an
ordered ring does not provide; they are out of scope.
