== HANDOVER — Neural-convergence theorems: Agda first, constructive reals

=== Mission

Two theory obligations are open in the proof ledger
(`+verification/proof-ledger.jsonl+`, rows `+pagerank-convergence+` and
`+esn-echo-state+`; rendered in `+verification/PROOF-STATUS.adoc#proof-ledger+`):

* *PageRank:* the damped power iteration in `+lib/neural/graph_of_trust.ex+`
  converges to a unique stationary vector.
* *ESN:* with the reservoir scaled as `+lib/neural/echo_state_network.ex+`
  scales it, two state trajectories under the same input converge
  geometrically (the echo-state property), and `+[-1, 1]ⁿ+` is invariant.

Both are *theory* (PROOF-POLICY §1): the source of truth is an Agda proof,
rechecked in Rocq and Lean. The owner chose (2026-11-09) to state them over
*constructive reals*, so the theorems are the textbook ones and not
rational approximations of them.

This supersedes the earlier version of this handover, which planned the
proofs in Lean 4 with Mathlib. PROOF-POLICY forbids Mathlib as a
dependency (§2) and puts theory in Agda first; that plan is withdrawn. The
Lean files `+PageRankInvariants.lean+` and `+ESNSpectralScaling.lean+` prove
natural-number *preconditions* only. Under PROOF-POLICY §3 they are
engineering evidence, not legs of these theorems.

=== Constraints

* Every file checks under the canonical invocation (PROOF-POLICY §2.1):
  `+agda --safe --without-K --cubical-compatible+`, Agda `+2.8.0.2+`
  (the version CI pins). No `+postulate+`, no `+--cubical+`, no
  `+TERMINATING+` or other unsafe pragma.
* One dependency: agda-stdlib, pinned to a release tag and commit that
  the receipt records. Feasibility checked 2026-11-09: agda-stdlib `+v2.3+`
  (commit `+8326c7475af1fa456ca04a0203c168d5d7ff842b+`) loads
  `+Data.Rational+` under the profile on Agda 2.8.0.2, and a Bishop-real
  record over it type-checks. The first check builds the library (about two
  minutes); later checks take seconds.
* No real-analysis library is assumed. The reals are built here, small and
  only as far as the two theorems need.
* Hypotheses the runtime cannot discharge are *module parameters*, never
  postulates. A theorem proved for every activation that is 1-Lipschitz and
  bounded by 1 is a theorem; the claim that `+tanh+` is such an activation
  is its own ledger row.

=== Construction plan

Files live in `+verification/proofs/agda/NeuralConvergence/+`. Each milestone
checks on its own and lands as its own stacked PR, with its ledger rows.

M0 — reals (`+Reals.agda+`)::
Bishop regular sequences: `+x : ℕ → ℚ+` with
`+∣ x m - x n ∣ ≤ 1/(m+1) + 1/(n+1)+`. Equality `+x ≈ y+` iff
`+∣ x n - y n ∣ ≤ 2/(n+1)+` for all `+n+` (a setoid, not `+_≡_+`). Order,
`+_+_+`, multiplication by a rational, `+∣_∣+`, `+max+`, the triangle
inequality. Everything the theorems use carries an explicit modulus.

M1 — completeness (`+Complete.agda+`)::
A sequence of reals that is Cauchy with an explicit modulus has a limit
(the diagonal construction), and the limit is unique up to `+_≈_+`.

M2 — Banach, constructively (`+Contraction.agda+`)::
On `+Vec ℝ n+` under a norm with the triangle inequality, a map with a
rational modulus `+0 ≤ c < 1+` has a fixed point, it is unique, and the
iterates satisfy `+‖xₖ - x*‖ ≤ cᵏ / (1 - c) · ‖x₁ - x₀‖+`. The rate is the
modulus of convergence, so the statement is constructive by construction.

M3 — PageRank (`+PageRank.agda+`)::
`+G(x) = α·P·x + (1 - α)·v+` with `+P+` column-sub-stochastic (non-negative
rational entries, each column summing to at most 1) and a rational
`+0 ≤ α < 1+`. `+G+` is an ℓ¹ contraction with modulus `+α+`, because such a
`+P+` gives `+‖P x‖₁ ≤ ‖x‖₁+`. Then M2. State it for sub-stochastic `+P+`, not
only stochastic: the runtime builds sub-stochastic matrices. A node with no
outgoing edge gives a zero column. `+iterate_trust/4+` in
`+lib/neural/graph_of_trust.ex+` sums every parallel edge into a source's
out-weight but takes one of them into each target, so repeated outcomes
leak mass. The theorem then covers convergence for every runtime input. The
leak changes what the fixed point means, and is a runtime defect to fix in
the runtime, not to model. *Ledger:* `+pagerank-convergence+`
becomes `+proven+` at PWG-3 once this checks in CI.

M4 — ESN (`+EchoState.agda+`)::
`+F_u(x) = (1 - a)·x + a·σ(W·x + w·u)+` for a rational leak rate
`+0 < a ≤ 1+`, `+W+` with rational entries and induced ∞-norm (largest
absolute row sum) `+‖W‖∞ ≤ ρ < 1+`, and σ a module parameter that is
1-Lipschitz with `+∣σ t∣ ≤ 1+`. Show
`+‖F_u(x) - F_u(y)‖∞ ≤ (1 - a + a·ρ)·‖x - y‖∞+` for every input `+u+`.
Corollaries, by induction on the input sequence: two trajectories approach
each other geometrically, and `+[-1, 1]ⁿ+` is invariant. Frame it in the
∞-norm, *not* the spectral radius: the runtime has scaled by the induced
∞-norm (`+@reservoir_norm+` = 0.95) since 2026-10, and `+test/neural_test.exs+`
checks both that bound and the convergence of two initial states.
*Ledger:* `+esn-echo-state+` becomes `+proven+` at PWG-3.

M5 — tanh (`+Tanh.agda+`), its own row::
Construct `+tanh+` on the reals (a convergent series or continued fraction
with an explicit modulus) and prove it 1-Lipschitz and bounded by 1. Until
this lands, M4 holds for every such σ, and the row recording that `+tanh+`
is one stays `+open+`.

=== What the theorems do not cover

* The runtime uses IEEE floats. The theorems are about reals; the link from
  them to `+lib/neural/*.ex+` is the `+models-runtime-refinement+` row, which is
  `+open+` and names no evidence yet. `+test/neural_test.exs+` checks the ESN
  ∞-norm bound and the convergence of two initial states; it is a candidate
  for that row's evidence, not yet recorded as it.
* Matrix entries are rational in the model. The runtime's weights are
  floats, every one of which is a rational, so no generality is lost there;
  rounding during iteration is what the model does not see.

=== The recheck legs (after PWG-3)

PROOF-POLICY §2: transport each witness through Dedukti first, and re-prove
in Rocq and in Lean only where transport is unavailable. No Mathlib in the
Lean leg. A leg counts toward PWG-2i or PWG-2ii only once its statement has
been compared with the Agda statement and that comparison recorded
(`+RECONCILED+`, §2.2). Record each leg in the theory row's `+legs+` field.

=== CI

Add an `+agda-neural+` job beside the existing `+agda strict-profile check+`
job in `+.github/workflows/verify-proofs.yml+`. It should pin Agda
`+2.8.0.2+` and the agda-stdlib tag and commit, cache the stdlib interface
files keyed on that commit, and check every file in
`+NeuralConvergence/+` with the §2.1 invocation. A missing or failing checker
is a failure, never a skip. Its summary records what PWG-3 needs: the checker
version, the stdlib pin, the flags in force, the import cone and each
source digest (PROOF-POLICY §8.2).

=== Definition of done (per milestone)

. Every file in the milestone checks under the §2.1 invocation, locally and
  in CI.
. `+bash scripts/proof-ledger.sh check+` passes with the rows the milestone
  changes, and `+render --write+` has refreshed `+PROOF-STATUS.adoc+`.
. The PR body carries the receipt: checker version, stdlib pin, invocation,
  source digests and the run that checked them.

=== Gotchas already met

* Agda's `+1/_+` in `+Data.Rational+` is the inverse of a rational. For
  1/(n+1) write `(+ 1) / suc n`, with the integer constructor from
  `+Data.Integer+` and `+_/_+` from `+Data.Rational+`.
* Equality of reals is `+_≈_+`; every lemma about reals is up to it.
  Reaching for `+_≡_+` on reals is the usual first wrong turn.
