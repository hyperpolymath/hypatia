= Public-findings coverage matrix (first pass, 2026-11-13)

`matrix.json` holds one row per finding kind: source, id, severity, problem, published fix,
hypatia detection (`detected|partial|none|unassessed`), fix status, gap reason, evidence, URL.
It records ids, titles, severity, the problem and the fix, with the source URL. It copies no licensed text.

*Status: DRAFT.* Detection status comes from reading `lib/rules`, `scripts/ci-health` and grep hits.
Rows marked `partial` still need a fixture to prove or disprove them. Only the actionlint category
list was fetched live; the other rows are from knowledge and need verifying against each source URL.
Not yet ingested: the full CodeQL, Sonar and Semgrep rule lists, and per-rule lists for 20 linters
(`unassessed`).

Numbers: see `matrix.json` (regenerate counts from it; they change as rules land).

== Route (ADR 0003, cicd-squabbler#154; ADR 0004)
Each row has a `route`: `first-line` (squabbler FIX or ACT), `referral` (Hypatia answers with a
Bustfile), `owner-only` (needs a person), `noise` (advisory bot messages such as CodeRabbit and
Codex rate-limit or credit limits, per ruling R7), `upstream` (triage the job that should have
produced the missing input, for example a rollup or `upstream_artifact_missing`), or `unrouted`
(not yet assessed). Where a row names a squabbler rule in `sq_id`, the squabbler's classification
wins (ADR 0003). Rows from cicd-squabbler ADR 0004 are estate-specific and keyed by their SQ id.
`fixst` also takes `rerun` (squabbler ACT rules). Otherwise the value is a heuristic from fix
status and gap reason, not a ruling.

Rows whose evidence cites hypatia#1064/#1065/#1090 are set to `unassessed` until their detector
exists in this tree and is verified; the reconciliation thread reports them as detected or drafted.

== Squabbler rows (cicd-squabbler)
Rows with `source` `cicd-squabbler` and the `sq_id` field are keyed from
`crates/squabble-core/data/first-line-rules.tsv` on cicd-squabbler `main`, which is authoritative
(48 rules at e34a7dc: 21 FIX, 5 ACT, 3 REFER, 16 OWNER, 3 NOISE); ADR 0004's row ids match it.
Only SQ-LOCK-01 has an executor (`squabble relock`). Every other FIX or ACT row is a described
action, not automated, so no squabbler row here uses `fixst` `autofix`. Detection for SQ-GEN-03
and SQ-GEN-05 is Hypatia's (WF029, WF031), not the squabbler's.
