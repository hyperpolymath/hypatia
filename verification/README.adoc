= verification/ — Formal Proofs

Idris2, Lean 4, TLA+ and Agda proof sources for Hypatia's type-level guarantees.

== Contents

* `proofs/idris2/` — Idris2 proof files (`.idr`) asserting invariants over the
  normative ABI in `src/Hypatia/ABI/`
* `proofs/lean4/`, `proofs/tlaplus/` — Lean 4 and TLA+ proofs
* `proofs/agda/` — Agda correspondence model for the security-alert
  rule tables (`AlertTableCorrespondence.agda`; `PWG-3` receipt in
  `PROOF-STATUS.adoc`), and the models of the E0 qualification gate
  (`E0Model.agda`, `E0Import.agda`, `E0Agreement.agda`, `E0ImportInstance.agda`,
  and the generated `E0ModelTables.agda`)
* `PROOF-STATUS.adoc` — Current proof completion status

== Building Proofs

The `proofs/` tree is not an Idris2 package; each file is type-checked
independently, exactly as `.github/workflows/verify-proofs.yml` does it:

[source,bash]
----
cd verification/proofs/idris2
for f in *.idr; do idris2 --check "$f"; done
----

The Agda artefact is checked under the estate strict profile (capital
K). A missing `agda` binary is an open proof obligation, never a skip:

[source,bash]
----
cd verification/proofs/agda
agda --safe --without-K --cubical-compatible AlertTableCorrespondence.agda
----

The E0 models are checked the same way, each file in turn (they also carry
`--double-check` in their `OPTIONS` pragma). `E0ModelTables.agda` is generated
from the running Elixir; `test/e0_agda_mirror_test.exs` fails when it is stale.
After an intended change of the gate, regenerate it and recheck the model:

[source,bash]
----
E0_MIRROR_WRITE=1 mix test test/e0_agda_mirror_test.exs
cd verification/proofs/agda
for f in E0Model E0Import E0Agreement E0ModelTables E0ImportInstance; do
  agda --safe --without-K --cubical-compatible "$f.agda"
done
----

The theorems are about the models. Agreement of a model with the Elixir code is
tested on a finite table, not proved, and the header of each file says so.

The Idris2 *packages* in the repository are built separately:

[source,bash]
----
idris2 --build src/abi/hypatia-abi.ipkg      # the normative ABI (src/Hypatia/ABI/)
idris2 --build verify/hypatia-verify.ipkg    # verify/src/PipelineState.idr
idris2 --build src/abi/hypatia-abi-gen.ipkg  # the wire-enum generator (just abi-gen)
----

NOTE: `src/abi/hypatia-abi.ipkg` sets `sourcedir = ".."`, so it compiles the
modules under `src/Hypatia/ABI/`. The `.ipkg` files live in `src/abi/`; the
Idris2 sources they build do not.
